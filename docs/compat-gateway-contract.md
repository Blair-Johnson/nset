# Compatibility gateway implementation contract

The server-side Python gateway lives in python/nset_compat. Training code keeps official client imports and logging calls; only endpoint/auth configuration changes. TensorBoard uses a server-side event-file collector because its writers produce files, not HTTP requests. Native Rust remains the metric store and durable ingest service. Unsupported semantics must fail explicitly, never acknowledge and discard data.

## Shared interface (owned by gateway worker)

common.py exports Request(method: str, path: str, query: dict[str,str], headers: dict[str,str], body: bytes), with json() returning a JSON object or raising ProtocolError. Headers are lower-case. Response(status: int = 200, body: dict|list|bytes = ..., headers: dict[str,str] = ...) is the transport response. ProtocolError(status: int, code: str, message: str) exposes those attributes. Each protocol module exports handle(ctx, request) -> Response | None; None means route not claimed. Protocol modules import these from .common; no SDK runtime dependencies for gateway.

context.py exports CompatContext(native_url, token, data_dir, public_url). ctx.native is NativeTransport from upstream.py with request(method,path,payload=None,*,query=None,raw=None,content_type=...) matching the nset_client Transport interface. It returns decoded JSON or bytes. The gateway transport enforces an absolute request deadline and response byte limit, pins origin addresses after startup resolution, and closes active sockets during shutdown. Startup DNS resolution itself is synchronous; it is not covered by a request deadline. ctx.public_url and ctx.token are strings. ctx.lock_for(key: str) returns a reentrant per-key lock for atomic protocol operations. State locks must not be held globally during network IO.

ctx.state.get(namespace,key,default=None), put(namespace,key,value), delete(namespace,key), items(namespace) -> list[tuple[str,Any]], next_id(namespace,start=1) -> int. These use durable SQLite WAL/FULL transactions with thread safety. Values are JSON; namespaces/keys strings. put only returns after commit. next_id atomically reserves monotonically increasing IDs. Use protocol-prefixed namespaces.

Bulk indexed operations are get_many(namespace, keys) and put_many(namespace, values): reads use bounded IN queries in one snapshot, and writes prevalidate all JSON then commit atomically. Adapters use these for metric identities and stream offsets rather than scanning prior history. A POSIX directory lock enforces one context owner, and persistent backend-origin binding prevents accidental reuse against another native service.

ctx.ingest_metrics(run_id,batch_id,metrics,wait=True) -> receipt dict. Uses PUT /api/runs/{run_id}/ingest/{batch_id} with {'metrics':metrics}. Stable caller-provided batch IDs (1..128 ASCII alnum dot underscore hyphen), no legacy POST fallback. If wait, poll durable receipt until applied or bounded timeout; on timeout raise retryable error, receipt remains recoverable. No acknowledgment before native durable commit. Chunk caller batches to native max10000; canonical stable timestamp/identity on retries.

The caller batch identity is durably bound to its canonical payload. Every native chunk ID is a gw1-prefixed SHA-256 of gateway-v1, run ID, caller batch ID and chunk index, avoiding suffix collisions between callers. Native receipts must match the chunk identity and count before compatibility acknowledgement. Legacy string-only identity bindings fail explicitly rather than silently using a new mapping. Chunk replay is safe but a multi-chunk caller operation is not one atomic native transaction.

## Transport and launch

Gateway owns __init__.py, common.py, context.py, gateway.py, __main__.py and tests/test_compat_gateway.py. MLflow worker exclusively owns mlflow.py and tests/test_mlflow_compat.py. W&B worker exclusively owns wandb.py and tests/test_wandb_compat.py. TensorBoard worker exclusively owns tensorboard.py and tests/test_tensorboard_compat.py. Parent owns manifests, docs beyond this contract and integration scripts. Do not modify another worker's files.

Gateway CLI: python -m nset_compat --native-url URL --data-dir PATH --listen 127.0.0.1:PORT [--public-url URL] [--workers 16] [--max-body-bytes 33554432]. Token from NSET_TOKEN environment (required), not argv. Bind loopback by default. Startup emits listening URL without credentials. Expose make_server(ctx, host='127.0.0.1', port=0, workers=16, max_body_bytes=33554432) -> HTTPServer for real SDK integration tests; call serve_forever() in test thread, shutdown/server_close for cleanup. Server actual address available through server_address. Proxy unmatched paths (native /api and UI) to native backend with correct native auth; do not leak credentials to arbitrary hosts. Gateway authenticates API/protocol requests using bearer token or W&B HTTP Basic api:<token>, constant time. Static UI auth should match native UI usability. Bound handler threads, body bytes, decompressed bytes, socket timeout; reject transfer/chunking ambiguity safely. No credentials/request bodies in logs. Error envelope includes error_code and message for MLflow; GraphQL errors for W&B. Unknown protocol routes return unsupported errors, not misleading native success. Generic file/artifact storage is unsupported; no blob store or signed-URL authentication is provided.

Tests using actual SDKs can import make_server and CompatContext, create native tests.support.Server and start gateway in a temp directory. Dependency environment managed only by parent: pixi compat environment with mlflow-skinny, wandb, tensorboard, pillow. Workers may use its absolute Python executable once installed at integration worktree/.pixi/envs/compat/bin/python with PYTHONPATH set to their own worktree/python. Avoid heavy shared-target builds. Unit tests may fake native transport; clearly label not SDK conformance.
